# Ébano — Brigadeiros Artesanais

Primeira versão da loja online da Ébano, focada em encomendas de brigadeiros em Rio Verde, GO.

## Como abrir

Abra o arquivo `index.html` em um navegador. Não é necessário instalar nada.

## O que já funciona

- Carrinho de compras;
- Seleção de brigadeiros avulsos por sabor (R$ 4,00 cada; cada grupo fechado de quatro custa R$ 12,00);
- Opção de negociação direta pelo WhatsApp para pedidos avulsos a partir de 100 brigadeiros;
- Botões de quantidade com toque prolongado para aumentar ou diminuir mais rápido.
- Caixa com 4 (R$ 12,00), caixa degustação com 10 (R$ 25,00) e orçamento para cento;
- Finalização com resumo do pedido pelo WhatsApp;
- Escolha do contato entre Maria Eduarda e Thiago;
- Layout adaptado para celular.
